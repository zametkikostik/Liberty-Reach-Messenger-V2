# Two-device field test

1. Install APK on A and B
2. Unlock with `master`
3. Device A: QR / copy identity payload
4. Device B: paste → Start session
5. Send text, media, voice
6. Optional: set Worker URL on both (Security screen)
7. Background A, wake from B → notification/poll
8. Duress on A → wipe, reinstall clean
